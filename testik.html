Добро пожаловать в тренажёр Access

Этот тренажёр показывает, как работать в Microsoft Access на демоэкзамене (вариант В3 — стройматериалы).

📌 С чего начать на экзамене?

  1. Открыть Access → «Создать базу данных» → дать имя СтройМаркет.accdb
  2. В левой панели (Область переходов) нажать на «Таблицы» → создать таблицы через «Конструктор»
  3. На вкладке «Работа с базами данных» → открыть «Схема данных» → добавить все таблицы и создать связи
  4. Импортировать данные через «Внешние данные» → «Excel/CSV»
  5. Создать запросы, формы, отчёты через вкладку «Создание»

🎯 Ключевые отличия варианта В3 (ваш вариант)

  • ✅ Скидка больше 12% → фон строки #F4A460 (оранжевый)
  • ✅ Товара нет на складе → фон строки голубой
  • ✅ Фильтр — по производителю (выпадающий список)
  • ✅ Поиск в реальном времени (без кнопки «Найти»)
